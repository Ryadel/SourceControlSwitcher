BUILD
======

Requirements
------------
- Visual Studio 2022 (17.14 or later) or Visual Studio 2026, with the "Visual Studio extension development"
  workload (the VSSDK build tools also come from NuGet, so a plain MSBuild from those versions works too).
- .NET Framework 4.7.2 targeting pack.

Build
-----
Open SourceControlSwitcher.slnx and build (Ctrl+Shift+B), or from a Developer Command Prompt:

    msbuild SourceControlSwitcher.slnx -restore -p:Configuration=Release

The VSIX is written to target\Release\SourceControlSwitcher.vsix.

Key.snk is the strong-name key of the assembly. It is committed on purpose, as Microsoft recommends for
open-source projects: a strong name provides identity, not security.

Tests
-----
The detection and configuration logic is covered by unit tests that do not need Visual Studio:

    dotnet test SourceControlSwitcher.Tests\SourceControlSwitcher.Tests.csproj

Debug
-----
Press F5: Visual Studio starts an experimental instance (devenv.exe /rootsuffix Exp) with the extension
installed. Set Tools > Options > Source Control Switcher > General > Logging to Verbose and watch the
"Source Control Switcher" pane of the Output window. Starting VS with /log also records the messages in the
activity log.
